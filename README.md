# Ciência de Dados Aplicada: Projetos e Análises

Este repositório reúne projetos desenvolvidos ao longo da minha formação como Cientista de Dados pela EBAC, demonstrando a aplicação prática de técnicas de **análise exploratória**, **modelagem preditiva**, **classificação**, **clusterização** e **visualização de dados**. Os trabalhos envolvem **resolução de problemas reais**, com foco em dados públicos, saúde, crédito e comportamento de clientes.
